- Quantity → Whole Number

- Customer Name → Customer

- Discount % → Discount

## Q4 Replace Values

- Cancelled → Cancelled Order

## Q7 Duplicate Column

## Q8 Merge Columns

## Q9 Add Custom Column
Create **Gross Sales = Quantity × Price**.

## Q10 Add Custom Column
Create **Net Sales = Gross Sales - (Gross Sales × Discount / 100)**.
