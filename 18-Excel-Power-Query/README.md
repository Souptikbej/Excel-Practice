# Power Query Basics Practice

## Objective
Practice Power Query transformations using **one dataset** in a logical ETL workflow.

## Workflow
1. Import Data
2. Change Data Types
3. Rename Columns
4. Replace Values
5. Split Columns
6. Extract Text
7. Duplicate Column
8. Merge Columns
9. Add Custom Column (Gross Sales)
10. Add Custom Column (Net Sales)
11. Conditional Column
12. Filter Rows
13. Sort Rows
14. Filter Net Sales >= 5000
15. Remove Unnecessary Columns
16. Group By
17. Load Data
