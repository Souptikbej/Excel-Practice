# Power Query Data Cleaning Practice

## Project Overview

This project is designed for beginners who want to practice real-world Power Query data cleaning operations used in Data Analyst roles.

The dataset intentionally contains common data quality issues found in business datasets, such as:

- Blank values
- Duplicate records
- Extra spaces
- Incorrect text formatting
- Missing values
- Data type issues

The objective is to clean and transform the dataset using Microsoft Excel Power Query.

---

# Skills Covered

This project covers the following Power Query operations:

- Remove Blank Rows
- Remove Duplicates
- Trim Extra Spaces
- Fix Data Types
- Replace Null Values
- Pivot Columns
- Unpivot Columns
- Convert Text Case
- Split Columns
- Replace Values

# Project Workflow

The recommended order for solving this project is:

1. Import Dataset
2. Remove Blank Records
3. Remove Duplicate Rows
4. Trim Extra Spaces
5. Fix Data Types
6. Replace Null Values
7. Convert Text Formats
8. Split Email Column
9. Replace Domain Values
10. Pivot Data
11. Unpivot Data
