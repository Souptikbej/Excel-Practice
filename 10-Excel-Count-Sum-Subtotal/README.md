# 📊 Excel Data Analysis Practice Set
## Topic: Aggregation Functions & SUBTOTAL

A hands-on Excel practice set designed for aspiring **Data Analysts**. This project focuses on learning how to summarize data efficiently using **Aggregation Functions** and the **SUBTOTAL** function.

---

# 📌 Objective

The objective of this practice set is to help beginners master Excel functions that are frequently used in real-world reporting and dashboard development.

After completing this practice set, you will be able to:

- Summarize large datasets
- Calculate KPIs
- Work with filters
- Create dynamic reports
- Understand the difference between SUM and SUBTOTAL
- Build dashboard-ready summaries

# 📖 Practice Topics

## 1. Aggregation Functions

Learn how to calculate:

- Total Sales
- Average Sales
- Maximum Sales
- Minimum Sales
- Number of Records

Functions Used

- SUM
- AVERAGE
- MAX
- MIN
- COUNT

---

## 2. COUNT vs COUNTA

Learn the difference between numeric counting and non-empty cell counting.

Functions Used

- COUNT
- COUNTA

---

## 3. SUBTOTAL with Filters

Understand how SUBTOTAL behaves when filters are applied.

Functions Used

- SUBTOTAL
- SUM

---

## 4. Hidden Rows vs Filtered Rows

Compare

- SUM
- SUBTOTAL(9)
- SUBTOTAL(109)

Learn which functions ignore hidden rows.
