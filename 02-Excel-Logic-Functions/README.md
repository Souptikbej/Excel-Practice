# 📊 Excel Logic Functions Practice

> A hands-on Excel practice project focused on mastering **Logic Functions** through real-world business scenarios. This repository simulates the daily tasks of a **Data Analyst** working with retail sales data.

---

## 📌 Project Overview

This project is designed to help learners understand how logical functions are used in industry rather than just memorizing formulas.

Instead of solving isolated examples, you'll work with **one realistic retail sales dataset** and complete business-oriented tasks that mimic what Data Analysts do in real organizations.

The goal is to develop logical thinking and decision-making skills using Excel.

---

## 🎯 Learning Objectives

After completing this project, you will be able to:

- Write conditional formulas confidently
- Automate business decisions
- Classify and categorize data
- Validate business rules
- Build dynamic reports
- Think like a Data Analyst instead of simply learning Excel formulas

# 💼 Business Scenario

Imagine you have joined a retail company as a **Junior Data Analyst**.

Every day, different departments require insights from sales data.

Your responsibility is to create calculated columns that help managers make business decisions using Excel Logic Functions.

Examples include:

- Identifying profitable orders
- Detecting late deliveries
- Finding high-value customers
- Flagging returned products
- Tracking target achievement
- Assigning customer loyalty levels
- Monitoring warehouse stock
- Creating executive reports

# 📝 Practice Sections

## 1️⃣ IF Function

Business decisions based on a single condition.

Examples:

- Profit or Loss
- High Value Orders
- Stock Availability
- Delivery Status
- Customer Satisfaction

---

## 2️⃣ AND Function

Business decisions requiring multiple conditions.

Examples:

- Bonus Eligibility
- Successful Deliveries
- Premium Rewards
- Excellent Orders

---

## 3️⃣ OR Function

Business decisions where any condition can be true.

Examples:

- High Risk Orders
- VIP Attention
- Promotion Candidates

---

## 4️⃣ NOT Function

Reverse logical conditions.

Examples:

- Non-returned Orders
- Non-Premium Customers
- Products outside Electronics

---

## 5️⃣ Nested IF

Multiple decision levels.

Examples:

- Sales Grades
- Profit Categories
- Delivery Performance
- Customer Ratings

---

## 6️⃣ IFS Function

Cleaner alternative to Nested IF.

Examples:

- Performance Grades
- Loyalty Categories
- Discount Recommendations

---

## 7️⃣ SWITCH Function

Match one value against multiple cases.

Examples:

- Payment Codes
- Region Managers
- Customer Levels
- Department Mapping
