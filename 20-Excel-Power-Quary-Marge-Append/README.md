# Power Query – Merge & Append Practice

## Topics
- Merge Queries (Join Tables)
- Append Queries (Stack Tables)

## Objective
Practice common Power Query operations used by Data Analysts.

### Merge
- Left Outer Join
- Expand Columns
- Create Custom Column

### Append
- Append Tables
- Sort
- Filter
- Aggregate (Sum)

## Workflow
1. Load data into Power Query.
2. Perform Merge or Append.
3. Apply required transformations.
4. Close & Load for reporting.
