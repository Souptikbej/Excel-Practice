# 📊 Excel Statistical Charts – Data Analyst Practice

Welcome to the **Excel Statistical Charts Practice Repository**.

This repository is designed for **Data Analyst Freshers** who want to practice the most commonly used statistical charts in Microsoft Excel.

The practice problems are inspired by real-world business scenarios similar to those used during training and interviews in top MNCs.

---

# 🎯 Objective

Learn how to analyze data using statistical charts and interpret business insights.

Instead of simply creating charts, you'll learn:

- Data preparation
- Frequency analysis
- Distribution analysis
- Defect analysis
- Outlier detection
- Business interpretation

---

# 📚 Topics Covered

## 1. Histogram

Learn to:

- Create bins
- Calculate frequency
- Analyze data distribution
- Identify concentration of values
- Interpret score distributions

---

## 2. Pareto Chart

Learn to:

- Sort data
- Calculate percentages
- Calculate cumulative percentages
- Apply the 80/20 Rule
- Identify the most critical problems

---

## 3. Box Plot

Learn to:

- Find Quartiles
- Calculate IQR
- Detect Outliers
- Understand Data Spread
- Compare distributions

# 🎯 Recommended Practice Flow

1. Read the business problem.
2. Understand the dataset.
3. Clean the data if required.
4. Perform calculations.
5. Create the required chart.
6. Interpret the results.
7. Explain the business insight.
