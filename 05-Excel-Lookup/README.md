# 🔍 Excel Lookup Functions Practice

A hands-on Excel project focused on mastering **Lookup & Reference Functions** through practical business scenarios commonly performed by Data Analysts.

Instead of isolated examples, this project uses multiple related datasets to simulate how analysts retrieve, enrich, and combine information across different tables.

---

## 🎯 Objective

The objective of this project is to develop strong lookup skills required for data cleaning, reporting, and data enrichment.

Functions Covered:

- VLOOKUP()
- HLOOKUP()
- XLOOKUP()
- INDEX()
- MATCH()
- INDEX + MATCH()

---

## 📊 Datasets

### Employee Master

After completing this project, you will be able to:

- Retrieve information from related datasets
