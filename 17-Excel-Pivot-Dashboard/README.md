# Sales & Profit Dashboard (Excel)

## Overview
This project is an interactive Excel dashboard built using **Pivot Tables, Pivot Charts, Slicers, Timelines, Calculated Fields, and Calculated Items**.

## Features
- KPI Cards (Sales, Profit, Profit Margin, Orders)
- Sales by Region
- Profit by Region
- Sales & Profit by Category
- Sales by Quarter
- Profit by Salesperson
- Profit Margin by Salesperson
- Interactive Slicers (Region, Salesperson)
- Timeline Filter (Date)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline
- Calculated Fields
- Calculated Items
- Conditional Formatting

## Dataset Columns
Order ID, Date, Region, Salesperson, Category, Product, Month, Sales, Cost, Quantity

## Calculations
- Profit = Sales - Cost
- Profit Margin % = Profit / Sales

## Business Insights
- East has the highest sales.
- West has the lowest sales.
- Electronics generates the highest revenue and profit.
- Furniture has the highest profit margin.
- Priya is the top performer by profit.
- Q3 records the highest sales.
