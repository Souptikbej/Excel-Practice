# Question 1

Create **Line Sparklines** for every employee.

### Requirements

- Create a new column named **Trend**.
- Insert Line Sparklines.
- Use monthly sales data (Jan–Jun).
- Place the Sparklines beside each employee.

# Question 2

Create **Column Sparklines**.

### Requirements

- Add a column named **Monthly Comparison**.

- Compare monthly values visually.

# Question 3

Create **Win/Loss Sparklines**.

### Requirements

- Add a column named **Performance**.
- Create Win/Loss Sparklines.
- Use the monthly data.
- Observe positive and negative months.

Build a Mini Dashboard.

| Employee | Line Trend | Column Trend | Win/Loss |
|-----------|------------|--------------|----------|

- Create a Line Sparkline
