# Excel Practice Series

## Topic
# Sparklines & Mini Graphs

This repository contains practice exercises designed for aspiring **Data Analysts** who want hands-on experience with **Microsoft Excel Sparklines**.

The exercises are based on real-world reporting scenarios commonly used in dashboards, MIS reports, KPI tracking, and management reporting.

---

## Difficulty Level

**Beginner → Intermediate**

---

## Prerequisites

- Basic Microsoft Excel knowledge
- Understanding of rows, columns, and cell references
- Familiarity with the Insert tab

---

## Learning Objectives

After completing this practice set, you will be able to:

- Create Line Sparklines
- Create Column Sparklines
- Create Win/Loss Sparklines
- Visualize trends inside cells
- Highlight High and Low Points
- Highlight First and Last Points
- Apply Sparkline styles and colors
- Build mini dashboard-style reports

## Business Scenario

You are working as a **Junior Data Analyst** in an MNC.

Your manager wants a dashboard that quickly shows the monthly performance of every employee without creating large charts.

Instead of traditional charts, you are asked to use **Sparklines** for compact and meaningful visualization.

Complete all the questions in **Practice_Questions.md** using the provided dataset.
