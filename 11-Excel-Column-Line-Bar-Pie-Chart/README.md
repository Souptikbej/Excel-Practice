# Excel Charts & Trendlines --- Data Analysis Practice

## 📊 Overview

This practice set is designed for **Data Analyst freshers** to build
practical Excel skills in **Charts & Trendlines**.

The exercises are based on a single business dataset so that you can
practice a realistic workflow instead of working with unrelated small
examples.

### Difficulty

**Beginner → Intermediate**

### Recommended Role Perspective

Act as a **Junior Data Analyst** supporting a retail company's
sales-management team.

------------------------------------------------------------------------

## 🎯 Learning Objectives

After completing this practice set, you should be able to:

-   Choose an appropriate Excel chart for a business question.
-   Create Column Charts for category comparison.
-   Create Line Charts for time-series trends.
-   Create Pie Charts for part-to-whole analysis.
-   Add and interpret Linear Trendlines.
-   Display a trendline equation.
-   Display and interpret the R² value.
-   Use trendline forecasting.
-   Add and interpret a Moving Average Trendline.
-   Communicate insights from charts rather than only reporting numbers.
-   Apply basic chart-design best practices.

# 📚 Practice Structure

There are **5 problems**.

  Problem     Main Skill
  ----------- -----------------------------
  Problem 1   Column Chart
  Problem 2   Line Chart
  Problem 3   Pie Chart
  Problem 4   Linear Trendline + Forecast
  Problem 5   Moving Average Trendline

------------------------------------------------------------------------

# 🚀 Recommended Workflow

For each problem:

1.  Understand the business requirement.
2.  Identify the required analytical view.
3.  Prepare/summarize the data needed for the chart.
4.  Select the appropriate chart.
5.  Add meaningful titles and labels.
6.  Format the chart for readability.
7.  Interpret the visual.
8.  Write a short business insight.

### Important

Do not treat chart creation as the final step.

A professional Data Analyst should be able to answer:

> **"What does this chart tell the business?"**

# 💼 Professional Standard

A good chart should be:

-   Simple
-   Accurate
-   Easy to compare
-   Properly labeled
-   Relevant to the business question
-   Free from unnecessary decoration

Avoid:

-   Too many colors
-   3D charts when unnecessary
-   Missing titles
-   Missing units
-   Excessive labels
-   Distorted axes
-   Charts that do not answer a business question

------------------------------------------------------------------------

## ⭐ Final Challenge

After completing all five problems, write a short management summary
answering:

> **"Based on the charts and trendlines, what is the most important
> sales insight management should know?"**

Your answer should use evidence from the visualizations.

------------------------------------------------------------------------

## 📌 Key Principle

> **Charts turn data into visual information. Trendlines help identify
> direction and possible future movement.**

The objective is not simply to create attractive charts. The objective
is to use charts to support **better business decisions**.
