# Excel Dynamic Array Functions Practice

A hands-on practice repository for mastering Excel Dynamic Array Functions used in Data Analysis.

This repository contains one business dataset and practice questions designed around real-world Data Analyst scenarios commonly performed in companies.

---

## Dataset

**File Name**

Employee_Sales_Data.xlsx

The dataset contains employee sales information including:

- Employee ID
- Employee Name
- Department
- City
- Sales
- Target
- Rating

This single dataset can be used to solve every practice question in this repository.

---

## Topics Covered

### 1. FILTER
Retrieve records dynamically based on one or multiple conditions.

Skills Learned

- Filter rows
- Multiple conditions
- Dynamic reports
- Dashboard source tables

---

### 2. SORT
Sort data dynamically without changing the original dataset.

Skills Learned

- Ascending sorting
- Descending sorting
- Multi-level sorting
- Alphabetical sorting

---

### 3. UNIQUE
Extract distinct values automatically.

Skills Learned

- Unique departments
- Unique cities
- Unique ratings
- Dynamic validation lists

---

### 4. RANDARRAY
Generate random sample datasets.

Skills Learned

- Random integers
- Random decimal values
- Matrix generation
- Sample data creation

---

### 5. SEQUENCE
Generate automatic number sequences.

Skills Learned

- Serial numbers
- Even numbers
- Multiplication tables
- Dynamic numbering

---
