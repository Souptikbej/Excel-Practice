# Excel LET & LAMBDA Functions Practice

A hands-on Excel practice repository designed for aspiring Data Analysts to master **LET** and **LAMBDA**, two powerful modern Excel functions for building clean, reusable, and efficient formulas.

This repository includes one business dataset and practice questions based on real-world reporting and dashboard scenarios commonly encountered in Data Analyst roles.

---

## Dataset

**File Name**

Employee_Performance_Sales_Data.xlsx

The dataset contains employee sales and performance information, including:

- Employee ID
- Employee Name
- Department
- City
- Sales
- Target
- Cost
- Bonus
- Working Days

The same dataset can be used to solve every practice question in this repository.

---

## Topics Covered

### 1. LET

The LET function allows you to assign names to calculations inside a formula, making formulas easier to read, maintain, and optimize.

#### Skills Learned

- Store intermediate calculations
- Reduce repeated calculations
- Improve formula readability
- Optimize workbook performance
- Build cleaner KPI calculations

---

### 2. LAMBDA

The LAMBDA function allows you to create your own reusable Excel functions without VBA.

#### Skills Learned

- Create reusable custom functions
- Reduce duplicate formulas
- Build business-specific calculations
- Standardize KPI calculations
- Improve dashboard maintainability
