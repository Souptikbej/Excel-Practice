# Excel LET & LAMBDA Practice Questions

**Dataset Used**

Employee_Performance_Sales_Data.xlsx

---

# Part 1 — LET Function

The following exercises are designed to improve formula readability and eliminate repeated calculations.

---

## Question 1

Using LET, calculate the **Profit**.

Formula:

Profit = Sales − Cost

---

## Question 2

Using LET, calculate the **Profit Margin (%)**.

Formula:

(Sales − Cost) / Sales

Display the result as a percentage.

---

## Question 3

Using LET, calculate the **Achievement Percentage**.

Formula:

Sales / Target × 100

Display the result as a percentage.

---

## Question 4

Using LET, calculate the **Net Earnings**.

Formula:

Sales − Cost + Bonus

---

## Question 5

Using LET, calculate the **Average Sales Per Working Day**.

Formula:

Sales / Working Days

---

# Part 2 — LAMBDA Function

Create reusable custom functions for the following business calculations.

---

## Question 1

Create a custom function named:

**PROFIT**

Returns:

Sales − Cost

Apply it to every employee.

---

## Question 2

Create a custom function named:

**PROFIT_MARGIN**

Returns:

(Sales − Cost) / Sales

Format the output as a percentage.

---

## Question 3

Create a custom function named:

**ACHIEVEMENT**

Returns:

Sales / Target × 100

Apply it to every employee.

---

## Question 4

Create a custom function named:

**NET_EARNING**

Returns:

Sales − Cost + Bonus

Use the function for the complete dataset.

---

## Question 5

Create a custom function named:

**BONUS_PERCENT**

Returns:

Bonus / Sales × 100

Format the output as a percentage.

# Business Challenge Exercises

These exercises simulate real-world Data Analyst tasks.

---

## Challenge 1

Create a reusable Profit Calculator using LAMBDA and use it throughout the workbook.

---

## Challenge 2

Using LET, calculate the Achievement Percentage once and classify employee performance:

- Excellent (≥110%)
- Good (100%–109.99%)
- Needs Improvement (<100%)

---

## Challenge 3

Create a reusable KPI function that returns Net Earnings.

---

## Challenge 4

Create a reusable function to calculate Daily Sales.

Formula:

Sales / Working Days

---

## Challenge 5

Create a dashboard-ready worksheet where all KPIs (Profit, Profit Margin, Achievement %, Net Earnings, and Daily Sales) are generated using LET or reusable LAMBDA functions.

---

# Learning Outcomes

After completing these exercises, you should be able to:

- Use LET to simplify complex formulas.
- Eliminate repeated calculations.
- Improve workbook performance.
- Build reusable Excel functions with LAMBDA.
- Standardize KPI calculations.
- Create cleaner and more maintainable business reports.
- Apply modern Excel techniques in real-world Data Analysis projects.
