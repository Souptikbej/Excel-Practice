# Excel Advanced Charts Practice Questions

## Instructions

- Use only the provided dataset.
- Do not modify the original data.
- Create professional-quality Excel charts.
- Wherever necessary, use Pivot Tables or formulas.
- After every chart, write at least **2–3 business insights**.

---

# Section 1 — Waterfall Chart (5 Problems)

### Problem 1

Filter the dataset where:

```
Record_Type = Financial
```

Create a **Waterfall Chart** using:

- Financial_Item
- Amount

Show the movement from **Opening Balance** to **Closing Balance**.

---

### Problem 2

Format the Waterfall Chart professionally.

Requirements:

- Different colors for Increase and Decrease
- Data Labels
- Currency Format
- Chart Title

---

### Problem 3

Identify:

- Largest Increase
- Largest Decrease

Highlight them using appropriate formatting.

---

### Problem 4

Convert:

- Opening Balance
- Closing Balance

into **Total** columns in the Waterfall Chart.

Verify whether the final balance matches the dataset.

---

### Problem 5

Prepare a management-ready Waterfall Chart.

The chart should clearly answer:

- Where did profit increase?
- Where did profit decrease?
- Which item had the greatest impact?

---

# Section 2 — Sunburst Chart (5 Problems)

### Problem 1

Create a Sunburst Chart using:

```
Company
    ↓
Department
    ↓
Team
```

Use **Amount** as the value field.

---

### Problem 2

Determine:

- Company with the highest Amount
- Company with the lowest Amount

Support your answer using the chart.

---

### Problem 3

Within each company:

Find the department contributing the highest Amount.

---

### Problem 4

Find the team contributing the highest Amount in the entire dataset.

Mention:

- Company
- Department
- Team

---

### Problem 5

Improve the chart by adding:

- Chart Title
- Data Labels
- Appropriate Colors

Then write **three business insights** based on the hierarchy.

---

# Section 3 — Treemap Chart (5 Problems)

### Problem 1

Create a Treemap Chart showing:

```
Category
```

using **Amount**.

---

### Problem 2

Calculate:

- Total Amount
- Category Contribution %
- Largest Category

Verify whether the Treemap visually matches your calculations.

---

### Problem 3

Rank all categories from highest to lowest Amount.

Compare your ranking with the Treemap.

---

### Problem 4

Format the Treemap professionally.

Requirements:

- Data Labels
- Category Names
- Values
- Readable Layout

---

### Problem 5

Write business insights based on the Treemap.

Include:

- Largest Category
- Smallest Category
- Category Contribution Pattern
- Business Recommendation

---

# Final Challenge

Using the same dataset, create a professional dashboard containing:

- Waterfall Chart
- Sunburst Chart
- Treemap Chart

Dashboard Requirements:

- Proper Alignment
- Consistent Theme
- Meaningful Titles
- Data Labels
- Professional Formatting

Finally, write an executive summary (100–150 words) explaining the key findings.
