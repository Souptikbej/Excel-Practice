# README.md

# Excel Advanced Charts Practice Dataset

A complete **MNC-style Data Analyst Practice Workbook** designed for Excel learners preparing for interviews and real-world business reporting.

---

## Objective

Practice creating and analyzing the following advanced Excel charts using **one unified dataset**.

- Waterfall Chart
- Sunburst Chart
- Treemap Chart

The dataset is designed so that every chart can be built without needing multiple Excel files.

# Dataset Overview

The dataset contains **295 records** and includes:

| Column | Description |
|---------|-------------|
| Record_ID | Unique identifier |
| Date | Transaction date |
| Company | Organization name |
| Department | Department within the company |
| Team | Team within the department |
| Category | Product/Sales category |
| Record_Type | Sales or Financial |
| Financial_Item | Used for Waterfall analysis |
| Amount | Numeric value used in charts |

# Topics Covered

## 1. Waterfall Chart

Learn to:

- Show financial movement
- Display increases and decreases
- Set Opening & Closing balances as totals
- Analyze contribution of each financial item
- Present management-ready financial reports

---

## 2. Sunburst Chart

Learn to:

- Visualize hierarchical data
- Build Company → Department → Team hierarchy
- Compare contribution at different levels
- Explore organizational structures

---

## 3. Treemap Chart

Learn to:

- Compare categories
- Display proportional contribution
- Analyze product/category performance
- Present value distribution

# Business Scenario

Imagine you have joined an MNC as a Junior Data Analyst.

Your manager has provided a raw business dataset and expects you to create executive dashboards using advanced Excel charts.

Your objective is to transform raw data into meaningful visualizations and communicate insights effectively.

---

# Best Practices

- Never create charts directly from raw data if summarization is required.
- Validate totals before chart creation.
- Use meaningful chart titles.
- Keep formatting simple and professional.
- Remove unnecessary chart elements.
- Use consistent colors.
- Add data labels only where they improve readability.
- Focus on business insights instead of decoration.
