# Problem 1 – Regional Sales Analysis

## Business Scenario

The Sales Director wants to know which region and category generated the highest sales.

### Create a Pivot Table

Rows

- Region

Columns

- Category

Values

- Sum of Sales Amount

### Questions

1. Which region generated the highest sales?
2. Which category generated the highest sales?
3. Which Region–Category combination generated the maximum sales?
4. What is the Grand Total Sales?

# Problem 2 – Monthly Sales Analysis

### Create a Pivot Table

# Problem 3 – Salesperson Performance

## Business Scenario

The HR department wants to evaluate salesperson performance.

### Create a Pivot Table

Rows

- Salesperson

Values

- Sum of Sales Amount
- Average of Sales Amount
- Count of Order ID
- Maximum Sales Amount
- Minimum Sales Amount

### Questions

1. Who generated the highest sales?
2. Who has the highest average sales?
3. Who handled the most orders?
4. What is the highest single sale by each salesperson?
5. What is the minimum sale handled by each salesperson?
