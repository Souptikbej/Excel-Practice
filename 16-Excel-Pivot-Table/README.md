# 📊 Excel Pivot Table Practice for Data Analyst Freshers

This repository contains practical Excel Pivot Table exercises designed for aspiring **Data Analysts**.

The problems are based on real-world business scenarios similar to those used in MNC Excel assessments.

---

# 📌 Skills Covered

- Creating Pivot Tables
- Rows, Columns, Values & Filters
- Date Grouping (Months)
- Grouping Data
- Summarizing Data
- Sum
- Average
- Count
- Max
- Min
- Drill Down
- Value Field Settings
- Business Insights
- Report Formatting

---

# 🎯 Learning Objectives

After completing these exercises, you will be able to:

- Build Pivot Tables from scratch
- Group dates into months
- Summarize large datasets
- Analyze sales performance
- Filter business data
- Create management reports
- Answer business questions using Pivot Tables

---

# 🧑‍💼 Business Scenario

You are working as a **Junior Data Analyst** in a retail company.

The Sales Manager provides raw sales data and asks you to generate reports for management using only Pivot Tables.

Your goal is to transform raw data into meaningful business insights.

# 💡 Best Practices

- Use meaningful field names.
- Format numbers with currency and commas.
- Rename Value Fields.
- Keep Pivot Tables clean and readable.
- Refresh Pivot Tables after data changes.
