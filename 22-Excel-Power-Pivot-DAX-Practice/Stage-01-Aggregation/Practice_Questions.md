# Practice Questions

## SUM()

1. Create a measure to calculate Total Sales.
2. Create a measure to calculate Total Profit.
3. Create a measure to calculate Total Discount.
4. Create a measure to calculate Total Quantity Sold.

---

## AVERAGE()

5. Create a measure to calculate Average Sales.
6. Create a measure to calculate Average Profit.
7. Create a measure to calculate Average Discount.
8. Create a measure to calculate Average Unit Price.

---

## MIN()

9. Find the Minimum Sales value.
10. Find the Minimum Profit value.
11. Find the Minimum Quantity Sold.

---

## MAX()

12. Find the Maximum Sales value.
13. Find the Maximum Profit value.
14. Find the Maximum Unit Price.

---

## COUNT()

15. Count the total number of orders.
16. Count the number of Sales records.

---

## COUNTA()

17. Count the number of Customer entries.
18. Count the number of Product entries.

---

## DISTINCTCOUNT()

19. Count the unique Customers.
20. Count the unique Products.
21. Count the unique Categories.
22. Count the unique Regions.

---

# Business-Oriented Questions

23. What is the highest sales value generated from a single order?

24. How many regions does the company operate in?

25. How many unique customers have placed orders?

# Instructions

- Create all answers as DAX Measures.
- Do not use calculated columns unless explicitly required.
- Use the most appropriate aggregation function for each question.
- Name measures using meaningful business-friendly names.
- Verify each measure before moving to the next question.
