# 📊 Excel Fundamentals Practice Project

A beginner-to-intermediate Excel project created to practice the core features of Microsoft Excel used in Data Analysis.

This project simulates an employee sales dataset and demonstrates spreadsheet management, formatting, formulas, data validation, navigation, and productivity techniques.

---

## Project Objective

The objective of this project is to build strong Excel fundamentals required for Data Analyst roles by practicing real-world spreadsheet operations on a single dataset.

---

## Dataset

**Dataset:** Employee Sales Data

Columns:

- Employee ID
- Name
- Department
- City
- Joining Date
- Salary
- Bonus %
- Sales
- Rating
- Phone
- Status

Total Records: 15 Employees
