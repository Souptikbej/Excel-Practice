# 📅 Excel Date & Time Functions Practice

A hands-on Excel practice project designed to master **Date & Time Functions** through realistic business scenarios commonly encountered by Data Analysts.

Instead of solving isolated examples, this project uses a single Customer Orders dataset to simulate real-world reporting, delivery analysis, and date-based business operations.

---

## 🎯 Objective

The objective of this project is to develop strong Excel skills for working with dates and time-related calculations used in business reporting and data analysis.

Functions Covered:

- DATE()
- TODAY()
- NOW()
- YEAR()
- MONTH()
- DAY()
- WEEKDAY()
- WEEKNUM()
- DATEDIF()
- EDATE()
- EOMONTH()
- NETWORKDAYS()
- NETWORKDAYS.INTL()
- TEXT()

---

## 📊 Dataset

This project uses a fictional Customer Orders dataset containing:

- Order ID
- Order Date
- Delivery Date
- Customer Name
- Region
- Order Status
- Sales

The dataset is designed to simulate common business scenarios such as delivery tracking, monthly reporting, working day calculations, and sales trend analysis.
