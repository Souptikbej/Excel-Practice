# Excel Data Analysis Practice - Sorting, Filtering & Conditional Formatting

A beginner-friendly Excel practice repository designed for aspiring Data Analysts.

This repository contains a realistic HR & Sales dataset along with practical exercises covering three of the most commonly used Excel operations in real-world data analysis.

---

# Dataset Overview

The dataset simulates employee records from different departments of a company.

### Number of Records

- 50 Employees

### Number of Columns

- 11 Columns

### Columns

| Column | Description |
|----------|-------------|
| Emp_ID | Employee ID |
| Employee_Name | Employee Name |
| Department | Employee Department |
| City | Work Location |
| Experience_Years | Total Experience |
| Salary | Monthly Salary |
| Performance_Rating | Employee Performance (1-5) |
| Sales | Sales Amount |
| Target | Assigned Sales Target |
| Joining_Date | Joining Date |
| Status | Active / Inactive |

## 1. Sorting

- Custom Sorting

## 2. Filtering

Practice:

- Auto Filter

## 3. Conditional Formatting

Apply:

- Highlight Cell Rules
- Duplicate Values
- Data Bars
- Color Scales
- Icon Sets
