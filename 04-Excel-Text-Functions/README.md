# 📘 Excel Text Functions Practice

A hands-on Excel practice project focused on mastering the most commonly used **Text Functions** through realistic business scenarios.

Instead of solving isolated examples, this project uses a single HR Employee dataset to simulate tasks that Data Analysts perform while cleaning and transforming data.

---

## 🎯 Objective

The goal of this project is to strengthen Excel text manipulation skills by solving practical, industry-inspired problems.

Functions Covered:

- LEFT()
- RIGHT()
- MID()
- LEN()
- TRIM()
- UPPER()
- LOWER()
- PROPER()
- SEARCH()
- FIND()
- SUBSTITUTE()
- CONCAT()
- TEXTJOIN()
- Ampersand (&)

---

## 📊 Dataset

The project uses a fictional HR Employee dataset containing information such as:

- Employee ID
- Employee Name
- Email
- Department
- City
- Employee Code
- Remarks

This dataset is intentionally designed to include inconsistent formatting, extra spaces, mixed letter cases, and structured employee codes to simulate real-world data cleaning scenarios.
