# Excel Data Analysis Practice – Data Cleaning Operations

A hands-on Excel practice repository designed for aspiring Data Analysts.

This repository focuses on the most common **Data Cleaning** operations used in real-world business environments before performing analysis.

---

## 🎯 Objective

Practice industry-level Excel data cleaning techniques using a single dataset.

These exercises simulate tasks commonly performed by Data Analysts in MNCs while preparing raw business data.

---

# Dataset

**File Name**

```
employee_sales.xlsx
```

The dataset contains employee sales records with duplicate entries, combined text columns, and multiple worksheets for merge practice.

Columns included:

| Column | Description |
|---------|-------------|
| Emp_ID | Employee ID |
| Full_Name | Employee Name |
| Department | Department |
| Region | Sales Region |
| Product | Product Sold |
| Sales | Sales Amount |
| Join_Date | Joining Date |
| Email | Employee Email |
| Phone | Phone Number |
| City_State | Combined City & State |
| Manager | Reporting Manager |
| Status | Employee Status |

# Topics Covered

## 1. Remove Duplicates

Practice:

- Remove duplicate records
- Remove duplicates using selected columns
- Identify duplicate entries
- Clean duplicate data
- Calculate results after removing duplicates

---

## 2. Find & Replace

Practice:

- Replace Product Names
- Replace Status
- Replace Region Names
- Replace Email Domains
- Replace Manager Names

---

## 3. Text to Columns

Practice:

- Split Full Name
- Split City & State
- Split Email
- Split Join Date
- Fixed Width Phone Split

---

## 4. Merge / Consolidate / Append

Practice:

- Merge tables using Emp_ID
- Append datasets
- Consolidate regional sales
- Create master tables
- Calculate Total Earnings
